# showlinenum.awk Test Suite

This directory contains unit tests for the `showlinenum.awk` script.

## Test Structure

```
tests/
├── inputs/         # Test input files (.diff files)
├── outputs/        # Expected output files (.out files)
├── run_tests.sh    # Test runner script
└── README.md       # This file
```

### File Naming Convention

Each test consists of:
- `XX_test_name.diff` - Input diff file in `inputs/`
- `XX_test_name.out` - Expected output in `outputs/`
- `XX_test_name.args` - (Optional) Command-line arguments in `inputs/`
- `XX_test_name.error` - (Optional) Expected error pattern in `outputs/` for failure tests

Where `XX` is a two-digit test number (01, 02, etc.).

## Running Tests

Run all tests:
```bash
./run_tests.sh
```

Run a specific test:
```bash
./run_tests.sh 01    # Runs test 01
./run_tests.sh 03    # Runs test 03
```

## Test Cases

### 01 - Basic Additions
**File:** `01_basic_additions.diff`
**Description:** Tests basic diff output with added lines. Verifies that line numbers are correctly added and that the `+` indicator is preserved.
**Options:** Default (show_header=1)

### 02 - Deletions
**File:** `02_deletions.diff`
**Description:** Tests diff output with deleted lines. Verifies that deleted lines show padding instead of line numbers and preserve the `-` indicator.
**Options:** Default

### 03 - Show Path
**File:** `03_show_path.diff`
**Description:** Tests the `show_path=1` option which prepends file paths to each line number.
**Options:** `show_path=1 show_header=0`

### 04 - Hide Hunk Headers
**File:** `04_hide_hunk.diff`
**Description:** Tests the `show_hunk=0` option which hides the `@@ ... @@` hunk headers while keeping other headers.
**Options:** `show_hunk=0`

### 05 - Removed File
**File:** `05_removed_file.diff`
**Description:** Tests handling of a completely removed file. All lines should show `~` as the line number indicator with the old file path.
**Options:** Default

### 06 - Binary File (Hidden)
**File:** `06_binary_file.diff`
**Description:** Tests default behavior for binary files. When `show_header=1` and `show_binary` is not explicitly set, binary file changes are shown in headers only.
**Options:** Default

### 07 - Binary File (Shown)
**File:** `07_binary_show.diff`
**Description:** Tests `show_binary=1` option which shows an empty format line (`:` only) for binary files that differ.
**Options:** `show_binary=1`

### 08 - Binary File Removed
**File:** `08_binary_removed.diff`
**Description:** Tests handling of removed binary files. Shows `~:` to indicate a removed binary file.
**Options:** `show_binary=1`

### 09 - No Newline at EOF
**File:** `09_no_newline.diff`
**Description:** Tests the handling of the `\ No newline at end of file` warning. The warning line should have padding instead of a line number.
**Options:** Default

### 10 - Multiple Files
**File:** `10_multiple_files.diff`
**Description:** Tests processing multiple files in a single diff output. Each file should be handled independently with correct line numbering.
**Options:** Default

### 11 - Large Line Numbers
**File:** `11_large_line_numbers.diff`
**Description:** Tests that large line numbers (9,999,998+) are displayed correctly without scientific notation.
**Options:** Default

### 12 - Multiple Hunks
**File:** `12_multiple_hunks.diff`
**Description:** Tests a file with multiple separate hunks. Line numbers should reset appropriately for each hunk.
**Options:** Default

### 13 - New File
**File:** `13_new_file.diff`
**Description:** Tests handling of a newly added file. All lines should be marked with `+` indicator.
**Options:** Default

### 14 - Path with Spaces
**File:** `14_path_with_spaces.diff`
**Description:** Tests handling of file paths containing spaces. The path should be correctly extracted and displayed.
**Options:** `show_path=1 show_header=0`

### 15 - Colon in Path
**File:** `15_colon_in_path.diff`
**Description:** Tests handling of paths with colons (e.g., `HEAD:file.txt`) when `allow_colons_in_path=1` is set.
**Options:** `show_path=1 allow_colons_in_path=1 show_header=0`

### 16 - Mnemonic Diff Format
**File:** `16_mnemonic_format.diff`
**Description:** Tests handling of mnemonic diff format which uses `i/` and `w/` prefixes instead of `a/` and `b/`. This is generated by `git diff --no-index` or with `diff.mnemonicPrefix=true` configuration.
**Options:** Default

## Error Test Cases

Error tests are identified by `.error` files in the `outputs/` directory containing the expected error pattern. The test runner expects the script to fail and verifies the error message contains the specified pattern.

### 90 - Combined Diff Format Error
**File:** `90_error_combined_diff.diff`
**Description:** Tests that combined diff format (used in merge commits with multiple parents) is properly rejected with an appropriate error message.
**Expected Error:** "Combined diff format not supported"

### 91 - Missing Path Info Error
**File:** `91_error_missing_path.diff`
**Description:** Tests that a malformed diff missing the `---` and `+++` path lines is detected and rejected.
**Expected Error:** "Line info found before path info"

### 92 - Colon in Path Error
**File:** `92_error_colon_in_path.diff`
**Description:** Tests that paths containing colons are rejected by default when `show_path=1` (to preserve parsing compatibility).
**Options:** `show_path=1`
**Expected Error:** "colons in path are forbidden"

## Adding New Tests

To add a new test:

1. Create an input file: `tests/inputs/XX_test_name.diff`
2. Create expected output: `tests/outputs/XX_test_name.out`
3. (Optional) Add arguments: `tests/inputs/XX_test_name.args`
4. (Optional) For error tests: `tests/outputs/XX_test_name.error`
5. Update this README with test description
6. Run `./run_tests.sh` to verify

## Test Coverage

The test suite covers:
- ✓ Basic diff operations (additions, deletions, unchanged lines)
- ✓ File operations (new files, removed files, multiple files)
- ✓ Binary files (modified, removed)
- ✓ Display options (show_path, show_header, show_hunk, show_binary)
- ✓ Edge cases (large line numbers, multiple hunks, no newline at EOF)
- ✓ Path handling (spaces in paths, colons in paths)
- ✓ Multiple diff formats (standard, mnemonic)
- ✓ Error conditions (combined diffs, missing paths, invalid options)
- ⚠ Color output (to be added)
- ⚠ ANSI escape code handling in input (to be added)

## Notes

- Tests use `gawk` (GNU AWK) which is required by showlinenum.awk
- The test runner compares exact output including whitespace
- Failed tests show a diff between expected and actual output
